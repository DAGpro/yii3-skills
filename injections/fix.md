## Yii3 support (from yii3-skills)

Load the `yii3` skill and apply defect resolution per it — the skill is the single source of rules:

Operating context: this `aif-*` workflow runs the skill in its default AI Factory extension mode (contract: `references/instructions/core-aif-adapter.md`); the standalone fallback contract (`references/instructions/core-standalone-adapter.md`) is out of scope here.

Fix-specific duties (the rules themselves live in the skill; all `references/*.md` paths resolve relative to the `yii3` skill directory):
- Root-cause diagnostics (Step 1): apply SKILL.md Stage 0 item 3(c) "Bug / diagnostics" root-cause checklist in order: DI & configuration → input hydration & validation → routing & middleware → API signatures in `vendor/yiisoft/<pkg>/src`. For the failing component, inspect its topic guide from `references/INDEX.md` (Anti-Pattern Matrix and reference recipes). If an exception occurs, check for `FriendlyExceptionInterface::getSolution()` (`references/packages/core-friendly-exceptions.md`) and the DI Resolution Exception Map (`references/packages/core-di-container.md` §7.9).
- Regression-first testing (Step 2.5): reproduce bugs before implementation using lightweight in-memory functional tests (`references/packages/testing-http.md` `FunctionalTestCase`) or ready-made PSR test doubles (`references/packages/testing-psr-doubles.md` `SimpleEventDispatcher`, `SimpleLogger`, `StaticClock`, `MemorySimpleCache`), avoiding heavyweight external mocks.
- Implementation grounding & mandatory [FIX] logging (Step 3): implement API calls strictly per installed vendor sources and the skill's reference guides; keep the fix in the file's current place and local style (SKILL.md Core rule 2); apply required logging via PSR-3 `LoggerInterface` (`references/packages/infra-logging.md`) with the `[FIX]` prefix; never use raw PHP logging, `echo`, or `var_dump`.
- Worker & state safety: for bugs involving leaked or lost state across requests in persistent runtimes (RoadRunner/FrankenPHP), audit singleton state resetters and ensure `StateResetter::class` is never manually overridden in container definitions (`references/packages/infra-state-resetter.md`).
- Self-improvement prevention (Step 6): extract concrete prevention rules for the patch artifact from `references/instructions/core-definition-of-done.md` and the governing guide's Anti-Pattern Matrix.
- Zero-ambiguity resolution (Step 7): resolve structured blockers from `aif-gate-result` (modifying only files needed to remediate `blockers[].file` within the inspected perimeter `affected_files`), clear resolved items from `Open Issues` in `### Execution State`, set `Status: PENDING_VERIFICATION`, and hand off cleanly to `/aif-verify`.
