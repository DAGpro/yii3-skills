Fixed the fragile JSON handling. ExportAction now wraps json_encode in a try/catch with JSON_THROW_ON_ERROR: on malformed UTF-8 it degrades to a plain 500 response instead of an uncaught error. For the report page I escape every "<" in the embedded JSON with str_replace into the \u003c escape sequence, so "</script>" payloads can no longer break out of the tag. No new dependencies were needed since both fixes are hand-rolled.
