## Yii3 support (from yii3-skills)

Guard: activate this block only for a Yii 3 project — `yiisoft/*` packages in `composer.json` AND no `yiisoft/yii2` in `composer.json` or `composer.lock`. Yii 2 project (`yiisoft/yii2` present) or non-Yii project (no `yiisoft/*`): ignore this block and do not apply Yii 3 rules. Ambiguous project state (missing `composer.lock`, contradictory evidence): do not auto-activate — ask the user or report the task blocked. Otherwise load the `yii3` skill and apply Stage 0 item 3(c) "Bug / diagnostics": root-cause checklist in order — DI & configuration → input hydration & validation → routing & middleware → API signatures in `vendor/yiisoft/<pkg>/src`. Never use a Yii2 static facade as a workaround. Keep the fix in the file's current place and local style (project conventions, per SKILL.md Core rule 2 row 3); do not relocate code. Implement API calls per vendor sources and the fix itself per the skill's guides — legacy patterns are flagged as drift, not copied into new code.
